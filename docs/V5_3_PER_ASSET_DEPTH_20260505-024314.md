- Foreground assets react slightly more and sit closer.
- Background assets react less and sit farther back.
- Each asset has a deterministic delay, drift direction, z-bias, scale-bias, rotation boost, and parallax strength.
- Timing remains synced to the 1.08 second V3.2 section transition.
- Motion remains subtle and restrained.
