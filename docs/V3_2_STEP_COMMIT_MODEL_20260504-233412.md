## Behavior

- Wheel down commits to the next sweet spot.
- Wheel up commits to the previous sweet spot.
- Swipe up/down works on touch screens.
- ArrowDown/PageDown/Space/Enter go forward.
- ArrowUp/PageUp/Backspace go backward.
- Home goes to spot 0.
- End goes to the final spot.
- There is no stable half-transition state.
- Mobile under 900px remains normal document flow.
- prefers-reduced-motion remains normal document flow.
